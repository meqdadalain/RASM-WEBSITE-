# 15 — AI Assistant

## Purpose

The AI Assistant explains engineering findings.

It helps engineers understand detected issues.

It does not replace engineering judgment.

---

# MVP Approach

The MVP uses curated engineering responses.

Responses are written by engineering experts.

No live LLM is required.

---

# Capabilities

The assistant can:

- explain an issue
- explain a rule
- explain the engineering impact
- suggest corrective actions

---

# Example Questions

Why is this issue critical?

What standard is violated?

How can this be corrected?

Which component is affected?

---

# Response Structure

Each answer contains:

Summary

Engineering explanation

Rule reference

Impact

Recommendation

---

# Pilot Evolution

The Pilot introduces:

- LLM
- RAG
- Issue context
- Rule database

---

# Series A

Future versions may support:

- conversational engineering review
- project memory
- standards search
- report generation

---

# Design Principle

Every AI response must remain explainable.

Trust is more important than creativity.
