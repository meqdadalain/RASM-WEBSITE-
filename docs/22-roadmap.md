# 22. Product Roadmap

## Horizon 1 — MVP Demo

Objective:

Demonstrate engineering value.

Deliverables:

- Demo model
- Viewer
- Issue catalog
- Dashboard
- AI explanations
- PDF report

Success:

Prospect requests a pilot.

---

## Horizon 2 — Pilot Platform

Objective:

Analyze customer models.

Deliverables:

- IFC upload
- Processing pipeline
- Rule engine
- Authentication
- Shared reports

Success:

First paying pilot.

---

## Horizon 3 — Product Platform

Objective:

Industrial SaaS.

Deliverables:

- Multi-project
- Multi-tenant
- AI Copilot
- Knowledge Base
- Integrations

Success:

Repeatable enterprise deployment.

---

# Guiding Principle

Always build the smallest feature that creates measurable engineering value.

Never build platform features before customer validation.
