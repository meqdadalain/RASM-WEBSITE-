# 11 — Pilot Roadmap

## Purpose

This document defines the evolution of RASM beyond the MVP.

The roadmap is divided into three horizons.

Each horizon introduces only the capabilities justified by customer validation.

---

# Horizon A — MVP Demo Engine

Target:

Investor demonstrations and first industrial prospects.

Objectives:

- demonstrate product vision
- validate customer interest
- secure pilot discussions

Capabilities:

- one industrial model
- predefined engineering issues
- 3D visualization
- AI explanations
- engineering dashboard
- PDF report
- pilot request form

No backend required.

Success criteria:

- successful demonstrations
- pilot requests
- customer validation

---

# Horizon B — Pilot Platform

Target:

First paying pilot customers.

Objectives:

Analyze customer models.

New capabilities:

- user authentication
- file upload
- IFC support
- asynchronous analysis
- analysis history
- issue status
- report sharing
- engineering rule engine
- LLM assistant
- cloud storage

Architecture additions:

- storage
- worker pipeline
- database
- analysis service

Success criteria:

Customers upload their own models and validate detected issues.

---

# Horizon C — Enterprise Platform

Target:

Multi-customer SaaS platform.

Objectives:

Scale across organizations.

Capabilities:

- organizations
- projects
- teams
- RBAC
- SSO
- audit trail
- rule management
- knowledge base
- APIs
- CAD integrations
- BIM connectors
- model version comparison
- analytics
- administration
- billing

Architecture additions:

- scalable backend
- multi-tenant database
- API gateway
- event-driven services
- monitoring
- enterprise security

# Product Evolution

The product evolves according to customer demand.

Never build capabilities before they are required by pilots.

Priority order:

1. Demonstrate value.
2. Validate with customers.
3. Build only what pilots require.
4. Generalize into a scalable platform.

---

# Guiding Principle

The roadmap follows one rule:

> Build the smallest product capable of earning the first industrial pilot, then evolve only through validated customer needs.
